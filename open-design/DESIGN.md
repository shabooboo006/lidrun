# LidRun UI 设计约束

## 设计目标

LidRun 是 macOS 菜单栏工具，不是网站、落地页或完整桌面窗口。主界面必须像一个真实的菜单栏弹出层：紧凑、可信、低装饰，第一眼能理解“合盖后任务继续运行”。

## 画布与结构

- 主画布包含顶部 macOS 菜单栏、LidRun 菜单栏图标、锚点箭头和一个弹出层。
- 弹出层宽度固定约 `360px`，高度约 `620px`。
- 弹出层锚定在右上角菜单栏图标下方，不能做成居中卡片或网页式面板。
- 底部状态与“高级设置… / 关于 / 退出”固定在弹出层底部；中间的保护规则和设置可以滚动。

## 字体

- 只使用 Apple 系统字体栈：
  `-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", "PingFang SC", "Hiragino Sans GB", "Helvetica Neue", system-ui, sans-serif`
- 中文界面默认由 PingFang SC 呈现，英文品牌名 `LidRun` 由 SF Pro Rounded（`Font.system(design: .rounded)`，仍属 Apple 系统字体栈）呈现，小号并与菜单栏图标组成锁定字标。
- 标题使用 700 字重；分区标题、行标题使用 600；状态、说明、数值使用 400-500。
- 不使用 Inter、Roboto、Arial、衬线字体或装饰字体。

## 颜色与材质

- 背景为浅色 macOS 桌面语境，不使用营销页渐变。
- 弹出层使用浅色半透明 material：白色/浅灰叠加模糊与轻微饱和度。
- 激活色仅使用 macOS System Blue `#0A84FF`。
- 蓝色只用于激活开关、选中的持续时间、菜单栏激活图标和核心授权状态。
- 危险状态只用于温度/电池等保护规则，保持低饱和提示，不做大面积警告色。

## 圆角、阴影与分隔

- 弹出层、分组、按钮圆角不超过 `8px`，原生圆形控件和开关除外。
- 不使用卡片套卡片、重阴影或玻璃拟态装饰。
- 分隔线使用低透明度系统灰，优先靠间距和分组表达层级。
- 弹出层可以有 macOS 原生浮层阴影，但内部控件不加投影。

## 组件规范

- 顶部 Header：左侧为 `LidRun` 和状态行，右侧为大号原生开关。
- 主模式行：必须展示“合盖运行”、说明文案和权限状态；这是 LidRun 的核心差异点。
- 持续时间：8 个圆形预设按钮等分排布，包含 `∞ / 15 / 30 / 45 / 1h / 4h / 8h / 自定义`；选中项为蓝底白字。
- 保护规则：使用严肃、低装饰的行列表，每行左侧圆形图标，右侧原生小开关。
- 设置：每行左侧圆形图标，中间粗体标签，右侧为开关、快捷键值或 chevron。
- 菜单栏图标：默认单色，激活时允许使用蓝色；图形语义为“笔记本合盖 + 继续运行信号”。

## 文案

- 所有可见 app UI 文本使用简体中文，品牌名 `LidRun` 保留英文。
- 文案必须短，接近系统设置口吻。
- 不使用营销口号、功能介绍段落、解释性徽章或设计过程文字。

## 交互

- 主开关切换激活/未激活状态，并同步菜单栏图标、状态行和底部当前状态。
- 点击持续时间预设应更新选中态和底部当前状态。
- 设置与保护规则开关必须具备可点击状态切换。
- 不放设计控制面板、主题切换器、平台选择器或 demo 标签。

## 禁止项

- 禁止做成网页 dashboard、落地页、hero 区或设置大窗。
- 禁止大面积渐变、插画、emoji、营销统计数字。
- 禁止非 Apple 默认字体造成的网页感。
- 禁止持续时间按钮被挤压、变椭圆、溢出或换行。
- 禁止把产品说明、设计规范或生成元数据渲染进最终 UI。
